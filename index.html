solus

is a lightweight lua-inspired interpreted language focused around doing everything my way

GitHub

Easily Embeddable

With a C API designed to be easier to get the hang of and manage state long term with than Lua's, you can easily integrate solus into your program, be it anything from game engines to servers, solus can be your entity scripts or it can be your config files.

Simple Syntax

The syntax of solus is simple to understand, but due to syntax features like operator short circuiting, operator overloading, and scopes-as-values it lends itself well to expressive styles of programming. Paired with the easy to understand closure system, it's easy to pick up solus' quirks.
